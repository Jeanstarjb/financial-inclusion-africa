# Data

The data is not included in this repository. Download it from the competition page after accepting Zindi's rules:
[zindi.africa/competitions/financial-inclusion-in-africa/data](https://zindi.africa/competitions/financial-inclusion-in-africa/data).

| file | rows | contents |
|---|---|---|
| `Train.csv` | 23,524 | respondents with the target `bank_account` (Yes/No) |
| `Test.csv` | 10,086 | respondents to predict |
| `VariableDefinitions.csv` | — | column descriptions |

Submission ID: `uniqueid + " x " + country`. The data comes from FinScope surveys run in Kenya, Rwanda, Tanzania and
Uganda between 2016 and 2018.
